# 💬 Chat Application (MERN Stack)

A real-time chat application built using the MERN stack with user authentication and messaging features.

---

## 🚀 Features

- 🔐 User authentication (JWT)
- 💬 Real-time messaging
- 👤 User session management
- 📦 RESTful API architecture
- 🎨 Responsive UI

---

## 🛠 Tech Stack

- MongoDB
- Express.js
- React.js
- Node.js
- JWT

---

## ⚙️ Installation

```bash
git clone https://github.com/yalog607/Chat-App.git
cd Chat-App
npm install
npm run dev
